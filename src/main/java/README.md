# RR-LPD5 - Ejercicio de Lógica de Programación 5

## Descripción

Este proyecto consiste en desarrollar un programa en Java que simula un pequeño diccionario Español-Inglés.

El programa almacena palabras y sus traducciones utilizando la estructura de datos `HashMap`. Posteriormente, selecciona aleatoriamente cinco palabras y solicita al usuario que ingrese su traducción al inglés.

Al finalizar, muestra la cantidad de respuestas correctas e incorrectas.

## Objetivo

Practicar los fundamentos de Java mediante el uso de estructuras de datos, colecciones, ciclos, condicionales y entrada de datos por consola.

## Tecnologías utilizadas

- Java
- HashMap
- ArrayList
- Collections
- Scanner

## Funcionalidades

- Diccionario con 25 palabras en español y sus traducciones al inglés.
- Almacenamiento de palabras mediante `HashMap`.
- Selección aleatoria de cinco palabras utilizando `Collections.shuffle()`.
- Captura de respuestas mediante `Scanner`.
- Validación de las traducciones ingresadas.
- Conteo de respuestas correctas e incorrectas.
- Resultados finales mostrados en consola.

## Cómo ejecutar el programa

1. Clonar el repositorio:

2. Abrir el proyecto en IntelliJ IDEA o en un entorno de desarrollo compatible con Java.

3. Ejecutar el archivo `Diccionario.java`.

4. Seguir las instrucciones que aparecen en consola e ingresar las traducciones correspondientes.

## Ejemplo de ejecución

```text
===== MINI DICCIONARIO ESPAÑOL - INGLÉS =====

1. perro: dog
¡Correcto!

2. casa: house
¡Correcto!

===== RESULTADOS FINALES =====
Respuestas correctas: 2
Respuestas incorrectas: 0
```
